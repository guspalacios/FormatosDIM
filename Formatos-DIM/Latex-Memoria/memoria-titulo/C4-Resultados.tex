\section{Resultados}

En esta sección se presentan los resultados obtenidos para cada uno de los sistemas fibra–matriz
evaluados. Los datos se reportan de manera objetiva y se acompañan de gráficos construidos a partir
de los registros experimentales procesados en las hojas de cálculo correspondientes. Los gráficos
incluyen los valores individuales, sus estadísticas descriptivas y la variabilidad asociada a cada
condición de ensayo. La interpretación de estos resultados se desarrolla posteriormente en la sección
de discusión.

\subsection{Resultados preliminares}

La Figura~\ref{fig:curvas_todas_probetas} muestra las curvas esfuerzo–deformación obtenidas para la
totalidad de las probetas ensayadas, utilizando un área embebida constante de 1.4~mm\textsuperscript{2}
y considerando únicamente el tramo comprendido entre 0 y 3.48~mm de desplazamiento. Este gráfico
proporciona una primera visualización del comportamiento general de las muestras, permitiendo
identificar la variabilidad entre probetas antes de separar los resultados por condición experimental.

Como se aprecia, las curvas presentan diferencias en pendiente, nivel de esfuerzo alcanzado y forma
general, lo cual es consistente con la dispersión esperable en ensayos de extracción a mesoescala.
Esta representación preliminar sirve como referencia para las comparaciones posteriores entre
proveedores de fibra y sistemas resina–fibra.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.9\linewidth]{grafica_todas_probetas.png}
    \captionsetup{justification=centering, singlelinecheck=false}
    \caption{Curvas esfuerzo–deformación para todas las probetas ensayadas, considerando un área
    embebida de 1.4~mm\textsuperscript{2} y un rango de desplazamiento de 0 a 3.48~mm.}
    \label{fig:curvas_todas_probetas}
\end{figure}
